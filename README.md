## Overview

### The challenge

Build a blog preview card that matches the design as closely as possible while remaining responsive and accessible.

Users should be able to:

- See hover and focus states for all interactive elements on the page.
- Read the content clearly at both mobile and desktop screen sizes.
- Experience a polished card layout with correct spacing, typography, and colors.

## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox for layout and centering
- Mobile-first responsive styling
- Local font loading with `@font-face`

### What I learned

This project helped me practice building a complete component layout using only HTML and CSS.

Highlights:

- Writing semantic HTML using `main`, `article`, `time`, and text-level elements.
- Using CSS custom properties for consistent color values.
- Applying responsive spacing and typography so the card works across screen sizes.
- Loading a local variable font and understanding how `font-weight` ranges can improve font usage.

### Continued development

In future projects, I want to focus on:

- Improving responsive typography so text scales more smoothly.
- Adding stronger keyboard accessibility and focus states.
- Learning more about CSS Grid for more advanced layouts.
- Exploring subtle animations to enhance interactive states.
